Metodkort läs först

A Obestämda balkar (elementarfall)

  • Räkna okända mot jämviktsekvationer. Fler okända = statiskt obestämt → deformationen måste in.
  • Ta bort stöd tills grundbalken finns i FS (vägg + fri = konsol 31.1, två stöd = 31.2). Varje borttaget stöd ger en okänd kraft och ett villkor i samma punkt: $\delta = 0$, eller $\delta = \Delta$ vid passningsfel.
  • Antal okända krafter = antal kompatibilitetsvillkor. Ett villkor per kraft, i punkten där kraften verkar.
  • Stödvillkor ger ekvation bara om stödet tagits bort. Annars sitter det redan i elementarfallet.
  • En delbild per kraft på samma grundbalk. Rita alla krafter åt tabellens håll (nedåt). Lägg ihop kolumnvis, med tecken. Minus i svaret = kraften verkar åt andra hållet.
  • Två balkar sitter ihop bara där något förbinder dem (distans, stång). Där uppstår kraften, där ställs villkoret. Övriga punkter: inget händer.
  • Hela längden eller halvor? Båda rätt. Hela konsolen (l = L) är enklast. Halvor (l = L/2) kräver limning: $\delta_C = \delta_B + \theta_B\, l$.

B Läsa FS 31.1 (konsol med punktlast)

ξ och α räknas båda från FRIA änden. α = var lasten sitter, ξ = var du mäter. β = 1 − α = avstånd från väggen.

  • Mäter du under lasten → raden $\delta(\alpha)$. Alltid, även om lastläget är en bokstav (β). En bokstav betyder bara "gäller för alla placeringar".
  • Mäter du mellan lasten och väggen → ξ > α. Mellan lasten och fria änden → ξ < α.
  • Konsol med last vid βL: biten bortom lasten är obelastad och rak, kapa den. $\delta_{\text{under lasten}} = \dfrac{P(\beta L)^3}{3EI}$. Vill du ha δ i spetsen behövs biten igen: $\delta_{\text{spets}} = \delta(\beta L) + \theta\cdot\alpha L$.
  • Maxwell: "P i B ger δ i C" = "P i C ger δ i B". Bra snabbkoll på tabellen.
  • FS 31.2: A/B är tabellens vänster/höger ände, inte uppgiftens bokstäver. Välj positivt håll för θ (medurs ↻ = lutar ner åt höger) och håll det genom hela uppgiften.

C Stångbärverk

  • Frihetsgrader först: fri knut 2 (u, v), stel bom med led 1 (Δ vinkelrätt mot bommen), stel bom i lodräta stänger 2 (rak linje: $\delta_2 = \tfrac12(\delta_1+\delta_3)$), fri stel kropp 3. Lika många jämviktsekvationer.
  • Knut = punkt: bara →, ↑. Inget moment. Stel kropp: →, ↑, moment (ta moment kring leden så försvinner reaktionerna).
  • Projektion: rör sig knuten mot (−) eller bort från (+) stångens fäste? Bara delen längs stången räknas: 45° ger $\cos 45° = 1/\sqrt2$.
  • Tabell: $\delta \to \varepsilon = \delta/L \to \sigma = E\varepsilon \to N = \sigma A$. Termo: $\sigma = E(\varepsilon - \alpha\Delta T)$. Givare visar ε(nu) − ε(vid limning).
  • $P_s$: största |σ| = σ_s. $P_f$: lås flytande stänger på ±σ_sA, bara jämvikt. Två flytande stänger i en knut = mekanism.
  • Notation: lilla δ = förlängning (stång) eller förskjutning (balk), stora Δ = givet passningsfel, σ = spänning.

D Lärarnas vanligaste avdrag

  • Obestämt problem utan alla tre delarna (jämvikt + kompatibilitet + material) = 0 p. Rubriker I, II, III.
  • Slutsvar med storheter som inte var givna. Dimensionsfel. Saknade enheter.
  • Ingen rimlighetskoll: tecken, enhet, specialfall (Δ = 0, k → ∞, β → 0).
  • Läs lydelsen: vad efterfrågas, vilka laster finns, två delfrågor.

Tenta 180113 U3 full lösning

Uppgift. Konsolbalk (EI, längd L) fast inspänd i A. Stöd vid B (x = L/2) och vid C (x = L). Stödet C sitter Δ ≪ L för lågt, balken skruvas fast i det. Bestäm reaktionskraften i B. (6p)

Stödet C ligger Δ under balkens oböjda läge. Streckat: balken efter fastskruvning.

0 Hur obestämd?

Okända: väggen ger $V_A, M_A$, stöden ger $R_B, R_C$ → 4 okända. Jämvikt ger 2 ekvationer. Alltså 2 gånger statiskt obestämd → två villkor från geometrin. Ta bort B och C, grundbalk = konsol med längd L (FS 31.1 fall 1). Väggen behöver inte friläggas, $R_B$ fås utan $V_A, M_A$.

I Jämvikt (friläggning)

Stöden ersätts med krafterna $P_B$ och $P_C$, båda ritade nedåt (samma håll som P i FS 31.1, så tabellen kan användas rakt av).

II Geometri (kompatibilitet)

  • Vid B: stödet sitter rätt → $\delta_B = 0$
  • Vid C: stödet sitter Δ för lågt, balken skruvas ner till det → $\delta_C = \Delta$ (nedåt)

III Material: elementarfall FS 31.1 fall 1

ξ, α från fria änden C. $\delta(\alpha) = \dfrac{PL^3\beta^3}{3EI}$ under lasten, $\delta(\xi>\alpha) = \dfrac{PL^3}{6EI}\big[(\xi-\alpha)^3 - 3\beta^2(\xi-\alpha) + 2\beta^3\big]$, $\delta(\xi<\alpha) = \dfrac{PL^3}{6EI}\big[-(\alpha-\xi)^3 \ldots\big]$ (ger talen nedan).

Delbild 1, bara $P_B$ ($\alpha=\beta=\tfrac12$): i B (under lasten) $\dfrac{P_BL^3}{24EI}$; i C ($\xi=0<\alpha$) $\dfrac{P_BL^3}{6EI}\left(-\tfrac18+\tfrac34\right) = \dfrac{5P_BL^3}{48EI}$.

Delbild 2, bara $P_C$ ($\alpha=0,\ \beta=1$): i C (under lasten) $\dfrac{P_CL^3}{3EI}$; i B ($\xi=\tfrac12>\alpha$) $\dfrac{P_CL^3}{6EI}\left(\tfrac18-\tfrac32+2\right) = \dfrac{P_CL^3}{6EI}\cdot\tfrac58 = \dfrac{5P_CL^3}{48EI}$.

Kontroll (Maxwell): "$P_B$ ger i C" = "$P_C$ ger i B" = 5/48 ✓

∑ Superposition + villkoren från II

$$\text{B:}\quad \frac{P_BL^3}{24EI} + \frac{5P_CL^3}{48EI} = 0 \qquad\qquad \text{C:}\quad \frac{5P_BL^3}{48EI} + \frac{P_CL^3}{3EI} = \Delta$$

Multiplicera båda med $48EI/L^3$:

Tolkning: $P_B$ ritades nedåt, minus = verkar uppåt. Stödet B trycker upp på balken.

Svar: $R_B = \dfrac{240EI\Delta}{7L^3}$ uppåt.

Dimension: $[EI\Delta/L^3] = \text{Pa}\cdot\text{m}^4\cdot\text{m}/\text{m}^3 = \text{N}$ ✓. Rimlighet: Δ = 0 ger $R_B$ = 0 ✓, styvare balk eller större Δ ger större kraft ✓. $P_C = +96EI\Delta/(7L^3)$ nedåt, stödet C drar ner balken, rimligt.

alt Facits väg: halvor (l = L/2) + matris

Facit använder konsol med längd $l = L/2$ och måste då limma för punkter utanför l.

$P_B$ ger: $\delta_B = \dfrac{P_Bl^3}{3EI}$ (direkt). $\delta_C = \dfrac{P_Bl^3}{3EI} + \underbrace{\dfrac{P_Bl^2}{2EI}}_{\theta_B}\cdot l$: mellan B och C ingen last i denna delbild, balken är rak där. C hänger ner lika mycket som B plus lutningen $\theta_B$ gånger längden l.

$P_C$ ger: $\delta_C = \dfrac{P_C(2l)^3}{3EI}$ (hela längden på en gång). $\delta_B = \dfrac{P_Cl^3}{3EI} + \dfrac{P_Cl\cdot l^2}{2EI}$: flytta $P_C$ från C till B = kraft $P_C$ i B plus moment $P_Cl$. Kraft i spetsen på konsol l ger $P_Cl^3/(3EI)$, moment i spetsen ger $Ml^2/(2EI)$.

Gemensam nämnare 6EI: $\tfrac13 = \tfrac26$, $\tfrac13+\tfrac12 = \tfrac56$, $\tfrac83 = \tfrac{16}{6}$:

$$\begin{bmatrix}\delta_B\\ \delta_C\end{bmatrix} = \frac{l^3}{6EI}\begin{bmatrix}2&5\\5&16\end{bmatrix}\begin{bmatrix}P_B\\P_C\end{bmatrix} \qquad \det = 2\cdot16-5\cdot5 = 7$$

Varför invertera? Vi vet δ (0 och Δ) och söker P. $\delta = AP \Rightarrow P = A^{-1}\delta$, "dela med matrisen". 2×2-regel: byt plats på diagonalen, byt tecken på de andra två, dela med det. Faktorn $l^3/(6EI)$ vänds också.

$$\begin{bmatrix}P_B\\P_C\end{bmatrix} = \frac{6EI}{7l^3}\begin{bmatrix}16&-5\\-5&2\end{bmatrix}\begin{bmatrix}0\\ \Delta\end{bmatrix} \;\Rightarrow\; P_B = \frac{6EI}{7l^3}(16\cdot0 - 5\Delta) = -\frac{30EI\Delta}{7l^3} = -\frac{240EI\Delta}{7L^3}$$

Bara rad 1 behövs när $P_B$ är sökt. Utan matris: lös $P_C$ ur första ekvationen, sätt in i andra. Samma poäng.

  2. Fel rad i FS 31.1. Fråga alltid: var sitter kraften (α), var vill jag veta δ (ξ)? Båda från fria änden. (Jag bytte etiketter på $P_C$-kolumnen: $PL^3/(3EI)$ är under lasten, alltså i C.)
  3. Glömma att $\delta_C = \Delta$, inte 0. Passningsfelet ÄR villkoret.
  4. Lägga ihop delbilderna utan tecken, eller rita $P_B$ och $P_C$ åt olika håll och blanda ihop.
  5. Ingen dimensionskoll och ingen tolkning av minustecknet.

Tenta 190112 U3 full lösning

Uppgift. Konsol (kEI, L) ovanför fritt upplagd balk (EI, L). Vid x = βL från väggen kläms en stel distans in som är Δ ≪ L för lång. Bestäm klämkraften P(β). För k = 14: vilket β ger minsta klämkraft? (6p)

Konsolen böjs UPP δ₁, balken NER δ₂. Inget förbinder balkarna utom distansen. α + β = 1.

Antaganden: linjärelastiskt, små deformationer (Δ ≪ L), distansen stel.

I Jämvikt

Frilägg distansen: den är en tryckt kloss. Trycker uppåt på konsolen och nedåt på balken med samma kraft P (Newton 3). En okänd, P. Som en stångkraft N: ett tal, två pilar.

II Geometri (kompatibilitet)

Gapet vid distansen är d oböjt och måste bli d + Δ. Båda mätta vid x = βL:

$$\delta_1 + \delta_2 = \Delta$$

En okänd → ett villkor, i punkten där den okända verkar. Stödvillkoren (δ = 0 i A och C för balken, δ = 0 vid väggen) sitter redan i elementarfallen och ger inga nya ekvationer. I C händer inget: inget förbinder balkarna där.

III Material (elementarfall)

Konsol, FS 31.1 fall 1. Lasten sitter βL från väggen. Biten utanför lasten är obelastad och rak, kapa den: konsol med längd βL belastad i spetsen.

$$\delta_1 = \frac{P(\beta L)^3}{3kEI} = \frac{P\beta^3L^3}{3kEI}$$

Fritt upplagd, FS 31.2 fall 1. Punktlast βL från vänster, αL från höger, nedböjning under lasten:

$$\delta_2 = \frac{PL^3\alpha^2\beta^2}{3EI} = \frac{PL^3\beta^2(1-\beta)^2}{3EI}$$

∑ Sätt in i II

$$\Delta = \frac{PL^3\beta^3}{3kEI} + \frac{PL^3\beta^2(1-\beta)^2}{3EI} = \frac{PL^3}{3kEI}\Big[\beta^3 + k\beta^2(1-\beta)^2\Big]$$

Bryt ut $PL^3/(3kEI)$: andra termen får då faktorn k.

Svar a): $P(\beta) = \dfrac{3kEI\Delta}{L^3\big[\beta^3 + k\beta^2(1-\beta)^2\big]}$

Dimension: Pa·m⁴·m/m³ = N ✓. β → 0 ger P → ∞ (distansen vid väggen) ✓. k → ∞ ger $P = 3EI\Delta/(L^3\beta^2(1-\beta)^2)$, bara balken böjs ✓.

b Pmin för k = 14

P minst när nämnaren $f(\beta) = \beta^3 + k\beta^2(1-\beta)^2$ är störst, β ∈ ]0, 1].

$$f'(\beta) = 3\beta^2 + k\big[2\beta(1-\beta)^2 - 2\beta^2(1-\beta)\big] = 3\beta^2 + 2k\beta(1-\beta)(1-2\beta) = 3\beta^2 + k(2\beta - 6\beta^2 + 4\beta^3)$$

DÄR POÄNG RYKER

  1. Två okända krafter ($P_B - P_C$) eller friläggning av stöd. Det är en inre kraft: en okänd, ett villkor.
  2. Villkor δ = 0 i stöd som inte tagits bort. Sitter redan i elementarfallet.
  3. Fel rad i FS 31.1. Mäter du under lasten är det alltid δ(α), och här räcker "konsol med längd βL".
  4. Tappa k vid utbrytningen. Skriva $(1-\beta^2)$ i stället för $(1-\beta)^2$. Tappa kvadraten på β i svaret.
  5. Lösa f' = 0 och stanna. Avgör vilken rot som är min, kolla ändpunkten β = 1, nämn att β = 0 ger P → ∞.
  6. Dela med β utan att säga β ≠ 0.

Tenta 210911 U3 kort

Uppgift. Balk över tre stöd (A, B, C), spann 2L, punktlast P på höger spann, spegel vid ett stöd. Laserstrålen vrids en vinkel φ. Bestäm P.

Nyckeln

Balk över 3 stöd = obestämd. Snitta vid mittstödet B, sätt in $M_B$ lika och motsatt på båda delarna. Varje del = fritt upplagd balk (FS 31.2) med sina egna laster + ändmomentet $M_B$ (fall 5, översta raden, tabell-$M_B$ = 0).

Kompatibilitet: samma θ vid B på båda sidor (balken har ingen knyck). Vänster spann (obelastat) bromsar vridningen från höger spann.

Superposition: θ från P och θ från $M_B$ adderas med tecken. Välj medurs ↻ positivt och håll det.

Optik: spegel vrids θ → strålen vrids 2θ. Läs av i figuren vad som är givet.

VAD JAG GJORDE FEL

Räknade höger spann som en egen fritt upplagd balk. Tog spannlängd L i stället för 2L. Vände $P = 16EI\theta/L^2$ fel. Underströk fel rad i FS 31.2 fall 5 ($M_A = M_B = M$ i stället för en ändmoment).

REGEL

Läs måtten i figuren för varje spann. Efter att ha löst ut P: kolla att enheten är N. FS 31.2 A/B = tabellens vänster/höger ände, översätt till uppgiftens bokstäver. Ett ändmoment → översta raden i fall 5.

Tenta 180113 U2 kort

Uppgift. Balk med linjärt växande utbredd last $q(x)$ från 0 vid A till $q_0$ vid B. Bestäm T, M och max böjspänning.

Nyckeln

Teckenkonvention GH figur 18 (s. 30): z uppåt, positiv q uppåt. Last nedåt skrivs med minus: $q(x) = -q_0 x/L$. $q_0$ är en konstant (N/m), x är var du är.

Global jämvikt: hela triangeln $Q = q_0L/2$ i tyngdpunkten 2L/3 från A. Gäller bara för reaktionerna.

Snitt vid x: den del av triangeln som är kvar har resultant $\dfrac{q_0 x^2}{2L}$ (area: bas x, höjd $q_0x/L$) och angriper x/3 från snittet (tyngdpunkten i en triangel ligger 1/3 från den tjocka änden).

$T(x)$ upp och $M(x)$ medurs på vänster del. Positivt M = "ledsen mun". $EIw'' = -M$, $dT/dx = -q$, $dM/dx = T$.

$I_y = bh^3/12$ med h i lastriktningen. $W_b = bh^2/6$, $\sigma = |M|_{\max}/W_b$.

VAD JAG GJORDE FEL

Tecknet på $R_A$. Lät lasten "angripa vid 2L/3" även i snittet. Missade faktorn x/3. Blandade ihop q (N/m) med Q (N).

REGEL

Resultant i tyngdpunkten är bara för jämvikt, aldrig för nedböjning. I ett snitt: rita om den kvarvarande lasten, räkna dess egen area och tyngdpunkt. Enhetskoll: q·längd = N.

Tenta 190112 U4 kort

Uppgift. Fyrkantsrör (konsol) med last P excentriskt, avstånd h/2 från axeln. Bestäm förskjutningen i hörnet.

Nyckeln

Flytta kraften till axeln + lägg till moment $M_v = P\cdot h/2$. Nu: en böjning (P på axeln) + en vridning ($M_v$).

Böjning: $\delta_b = PL^3/(3EI)$. Vridning: $\theta = M_vL/(GK)$, $G = E/(2(1+\nu))$.

Hörnet rör sig $\Delta = \delta_b + \theta\cdot h/2$ (vridning × hävarm). Snyggt uttryck: bryt ut största termen så det blir $\delta_b\,[1 + \ldots]$.

VAD JAG GJORDE FEL

Förstod inte hur böjning och vridning hänger ihop eller hur facit fick ett kort uttryck.

REGEL

Excentrisk last = kraft på axeln + moment. Två elementarfall, addera förskjutningarna i punkten. Bryt ut, kolla enhet.

Tenta 170114 U1 kort

Uppgift. Knut med tre stänger (en vågrät, en lodrät, en i 45°), last P. Stångkrafter, $P_s$ (begynnande plasticering) och $P_f$ (fullplasticering).

Nyckeln

Frihetsgrader: knuten är en punkt, 2 frihetsgrader (u, v) → 2 jämviktsekvationer (→, ↑). Inget moment. 3 stänger = 1 gång obestämd.

Projektion: en stång i taget. Rör sig knuten mot (−) eller bort från (+) stångens fäste? Bara delen längs stången räknas: vågrät 100 %, lodrät 100 %, 45° ger $(u \pm v)/\sqrt2$.

Tabell: $\delta_i \to \varepsilon_i = \delta_i/L_i \to \sigma_i = E\varepsilon_i \to N_i = \sigma_iA_i$. Sätt in i jämvikten, lös u, v.

$P_s$: största |σ| = σ_s (tryck flyter också). $P_f$: lås flytande stänger på ±σ_sA, bara jämvikt, nästa stång flyter. Två flytande stänger i en knut = mekanism = $P_f$.

VAD JAG GJORDE FEL

Tog moment för knuten som tredje ekvation. Förstod inte 1/√2 eller "till beloppet störst".

REGEL

Knut = punkt = 2 ekvationer. Belopp = |σ|. Ställ upp tabellen, den gör jobbet.

Tenta 210911 U1 kort

Uppgift. Stel skiva upphängd i stänger, last. Bestäm stångkrafter och skivans rotation.

Nyckeln

Jämvikt → N. Hooke $\delta = NL/(EA)$. Varje stång flyttar sitt hörn δ längs stången, bort från väggen om stången är dragen (väggänden står still, hela förlängningen hamnar i hörnet).

Rotation: titta från ena hörnet, $\theta = \dfrac{\text{skillnad i förflyttning tvärs kanten}}{\text{avstånd}}$. Motsatta håll ger summa: $\theta = (\delta_1+\delta_3)/L$.

Små deformationer: $\sin\theta \approx \tan\theta \approx \theta$ (rad), $\theta^2$-termer stryks.

VAD JAG GJORDE FEL

Trodde att skivan inte kan rotera eftersom den är i jämvikt. Förstod inte hur δ blir en förflyttning av hörnet.

REGEL

Rotation pga last = hur mycket skivan vridits från obelastat till nytt jämviktsläge. Jämvikt och rörelse utesluter inte varandra.

Tenta 160115 U1 kort

Uppgift. Stel bom med led i botten, hålls av två sneda stänger (vinkel φ), temperaturändring ΔT och/eller last. Stångkrafter.

Nyckeln

Frihetsgrad: stel bom med led → toppen rör sig bara vinkelrätt mot bommen, 1 obekant Δ. Moment kring leden = enda jämviktsekvationen som behövs.

Geometri: zooma in på toppen, dra vinkelrätt från förskjutningen mot varje stångs linje: $\delta_i = \pm\Delta\cos\varphi$. Stånglängd $L_i = L/\sin\varphi$.

Termo-Hooke: $\sigma = E(\varepsilon - \alpha\Delta T)$. Fri utvidgning ger ingen spänning, hindrad ger det.

VAD JAG GJORDE FEL

Lät toppen röra sig både vågrätt och lodrätt. Glömde cos φ och att $L_i = L/\sin\varphi$.

REGEL

Räkna frihetsgrader först. En frihetsgrad = en obekant förskjutning = en jämviktsekvation.

Tenta 230217 U1 kort

Uppgift. Stel bom hängande i tre lodräta stänger på lika avstånd, last. Stångkrafter.

Nyckeln

Frihetsgrader: stel bom i lodräta stänger → 2 (förskjutning + lutning) → 2 jämviktsekvationer (↑ och moment). 3 stänger = 1 gång obestämd.

Rak linje: bommen är rak före och efter. Lika avstånd ger $\delta_2 = \tfrac12(\delta_1+\delta_3)$. Det är kompatibiliteten, inga vinklar behövs.

Rita alla δ positiva (nedåt). Tecknet i svaret visar om en stång blev kortare.

VAD JAG GJORDE FEL

Försökte beskriva lutningen med sin θ och okända hypotenusor.

REGEL

Stel bom = rak linje. Mittvärdet är medelvärdet av ändarna. Små vinklar: inga sinus.

Töjningsgivare (M, Δ, ε₀)

Givaren visar ε(nu) − ε(när den limmades på), som tara på en köksvåg. Givare som visar 0 betyder inte otöjd stång.

Gör en tabell N, δ, ε per läge (före limning, efter last) och subtrahera. Hooke: $\varepsilon = \sigma/E$, inte σE (enhetskoll: ε saknar enhet).

Stel skiva med led + två stänger

Stel kropp i planet: alltid 3 ekvationer (→, ↑, moment). Ta moment kring leden så försvinner reaktionerna där.

$\delta_1 + \delta_2 = 0$ gäller bara två stänger i rad i samma punkt. Med led: förskjutning ∝ avstånd till leden (som en dörr). Rita deformerat läge och läs av.

FX 180220 U1 kort

Uppgift. Balk fast inspänd i A, stöd i B som sitter Δ för högt, last P. Bestäm $R_B$.

Nyckeln

Tre okända ($R_A, M_A, R_B$), två ekvationer → obestämd. Ta bort B, grundbalk = konsol (hela längden). En okänd $R_B$ → ett villkor i B: $\delta_B = \Delta$ (uppåt, stödet sitter för högt), inte 0.

Två delbilder: P ger δ i B, $R_B$ ger δ i B. Addera med tecken = Δ. Kolla med Δ = 0: ska ge $R_B = 5P/16$.

VAD JAG GJORDE FEL

Klippte balken vid P (efter förra uppgiftens bild) i stället för efter stöden. Satte $R_B = P$ med bara jämvikt. Skrev T(x), M(x) vid väggen. Missade Δ i villkoret.

REGEL

Stöden väljer tabell, lasterna väljer rad. Vid ett stöd heter det $R_A$, $M_A$. Passningsfel ger villkor ≠ 0.

De korta korten är kondenserade (mina detaljerade anteckningar från de passen är borta). Skicka dina anteckningar för en uppgift så fyller jag i den till full lösning. Tillbaka till ikapplistan.
